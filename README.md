# The Useless Game

A terminal game where you flip a switch on and off.

That's it. That's the game.

## Install

```bash
npm install -g the-useless-game
```

## Play

```bash
useless-game
```

Or without installing:

```bash
npx the-useless-game
```

## Controls

| Key     | Action       |
|---------|--------------|
| `SPACE` | Flip switch  |
| `Q`     | Quit         |

## Features

- A switch
- It goes on
- It goes off
- Achievements (for the dedicated)
- A timer tracking how long you've wasted

## Achievements

| Flips | Achievement               |
|-------|---------------------------|
| 1     | First Flip                |
| 10    | Double Digits             |
| 50    | Are You OK?               |
| 100   | Centurion of Boredom      |
| 500   | Deeply Committed          |
| 1000  | You Need Help             |
